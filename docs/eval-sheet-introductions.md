# 評価名簿の自己紹介

ロール付与による自動作成・定期更新・ニックネーム変更・評価期間延長で、同じ自己紹介取得処理を使用する。
本文はEmbedの自己紹介欄（最大1024文字）に表示し、元の投稿リンクも付ける。

## ロール別の投稿先

共有環境変数 `EVAL_SHEET_INTRO_CHANNELS_BY_ROLE` に、サーバーID → ロール名（完全一致）→ チャンネルID配列のJSONを設定する。
ロール別の指定がない場合は従来どおり `/evalsheet roster-category` の設定を使用する。

対象のロールは毎回最新の所属を取得して確認する。
指定がある場合はそのチャンネルのみを調べ、同じカテゴリ内の雑談などは検索しない。
複数チャンネルに本人の投稿がある場合、取得範囲内で最新の空でない本人の投稿を使う。
投稿が見つからなくてもカテゴリ全体へ検索を広げない。

対象は同じサーバーのテキスト・アナウンスチャンネル。各チャンネル最大500件まで遡る。
Botに閲覧・メッセージ履歴閲覧権限が必要で、投稿本文の取得にはMessage Content Intentも必要。
取得失敗はログへ記録し、他の指定先の検索は継続する。
ユーザーのロールやチャンネル権限、評価名簿の投稿先・評価期間は変更しない。

環境変数とコードを本番へ反映するには再公開が必要。
既存の有効な評価シートも次回の通常更新で同じ検索処理を使用するが、過去の終了済み・無効な評価シートは一括更新しない。
