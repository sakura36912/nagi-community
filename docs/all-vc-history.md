# 全VCの入退室履歴

多機能Botが参加しているサーバーで、Botが観測できる全VCの入退室を記録する。
通常VC、親カテゴリーのないVC、Hub転送先、ショップで作成した部屋、
プライベートVC、ステージVCを含む。旧 tracked-category 設定は履歴を制限しない。

- 保存する内容：サーバーID、ユーザーID、VC ID、入室日時、退室日時、追放者区分。
- 音声の録音・会話内容の保存は行わない。
- サーバー内および全体の記録拒否を維持する。プライバシー確認に失敗した場合は記録しない。
- 保存期間は既存のサーバー設定を維持する（未設定なら180日）。
- 酒場ランキング、酒場VCの滞在条件、報酬には、それぞれ既存の対象チャンネル条件を適用する。
- 再起動時は開いたままのセッションを閉じ、現在VCにいるユーザーを再観測した時点から記録する。
  停止中の正確な入退室は復元できず、古いセッションの退室日時が復旧時刻になる場合がある。
- 変更を反映するには多機能Botを再公開する。過去の未記録分は復元しない。
- BotがアクセスできないVC、Discordからイベントが届かない期間、DB停止中は完全な記録を保証できない。
