# 管理者による通貨付与

銀行Botの `/give user:ユーザー amount:金額` で、対象者のサーバー内残高へ通貨を新規付与します。
実行者からの送金ではなく、実行者の残高は減りません。

- Discordの「管理者」権限が必須です。サーバー管理権限だけでは使用できません。
- サーバー内のみ。Botや在籍を確認できないユーザーには付与しません。
- 金額は1〜2,147,483,647の整数。付与後の残高も2,147,483,647以下が必要です。
- 残高と取引履歴は同じトランザクションで保存し、失敗した場合は両方取り消します。
- 履歴には付与先・金額・実行者を保存します。同じDiscord操作IDは一度だけ処理します。
- 新しくコマンドを実行した場合は別の付与です。応答が届かなかった場合は、再実行の前に残高・履歴を確認してください。
- 結果は実行者にのみ表示します。

今回追加するのはユーザーへの付与のみです。旧 `/give wallet`・`treasury`・`deposit` の復活や、マイナス金額による没収は含みません。
廃止済みの `/guide`・`/leavelog`・`/roulette` は引き続き復活させません。

反映には銀行Botの再公開が必要です。新版は起動時に `/give` のみを個別登録・更新し、Discordから読み直して確認します。他のコマンドを全件置換しません。
旧プロセスが動いている間に定義だけを追加すると、旧版が削除したりコマンドを受け付けなかったりするため、先に新しいBotを稼働させてください。
