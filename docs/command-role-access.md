# コマンドの共通ロール制限

銀行Bot・多機能Botとも、島民ロールだけを理由に一般コマンドを拒否しない。
他の一般ユーザーと同じく、コマンドごとの利用条件を満たせば利用できる。

## 引き続き維持するもの

- 管理者専用の設定・残高操作・イベント管理などの権限チェック
- `/shop ticket-panel` の夜鴉・黒兵・Administrator限定
- その他のショップ管理操作の管理者限定
- 武器・ボスの本船員条件、ゲームの参加資格・役職条件
- カジノの回数上限、クールタイム、利用料金、各種対象ロール
- 追放者の利用制限と、従来のスタッフロールによるその免除

島民と追放者を両方持つ場合は追放者の制限が残る。
この変更ではDiscordの管理者権限の付与や、管理者専用コマンドの既定権限の解除は行わない。
公開中のBotへの反映には新しいコードでの再公開が必要。
