# 高級船室の購入時の所有者確認

高級船室は1人1室まで。所有者の確認は料金を引き落とす前に行う。

- 本人の有効な高級船室の保存記録があり、VCが存在する場合は新規購入を拒否する。
- 別人が所有者として保存されている高級船室は、購入者が招待されていても購入の妨げにしない。そのVCのパネルが消えていたり、メッセージ履歴を取得できなくても所有者の保存記録を優先する。
- フリールーム（`island`・旧`ura`）の記録は高級船室の所有扱いにしない。
- 無期限船室など所有者の保存記録がない候補は、Bot自身の所有者パネルを確認する。本人所有なら購入を拒否し、別人所有なら次の候補へ進む。
- 同じカテゴリにあるだけの通常VCは所有扱いにしない。保存記録もパネルもなく、`🔒 `接頭辞とBot自身の個別権限設定の両方がないVCは、個別閲覧権限があっても購入を妨げない。パネル確認が通信・権限エラーで失敗した場合は従来どおり請求しない。
- 所有者パネルが見つからない・所有者IDがない候補は未確認扱い。残りの候補も調べ、本人の船室が判明したらその案内を優先する。最後まで不明な候補が残る場合は請求せず停止し、該当VCのIDをBotログへ残す。

招待による閲覧権限だけを所有の証拠にしない。一方、所有者情報が本当に不明な部屋を無条件で無視して1人1室の制限を回避させない。
購入ボタンと商品選択メニューの両方で同じ確認処理を使用する。
この変更では既存VC・所有者データ・残高・チャンネル権限を変更しない。本番反映には再公開が必要。
