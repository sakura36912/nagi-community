# VCの画面共有

通常のHub転送先とショップのVCでは、所有者による画面共有ボタンを共通の権限処理で扱う。

- `@everyone` と、チャンネルに既にある全ロール・ユーザー上書きの `Stream` だけをON/OFFする。ロール・個別拒否がeveryoneの許可を打ち消す問題と、個別許可がOFFを打ち消す問題を防ぐ。
- 閲覧・接続・発言・アプリコマンド権限などは変更せず、カテゴリ同期も行わない。共有の許可だけで新しい人を非公開VCへ招待することはない。
- ロール経由の参加者にもeveryoneの画面共有設定が適用される。個別招待者だけに限定しない。
- 操作前と完了後にDiscordから最新のチャンネル設定を取得する。ON表示はeveryoneの明示許可があり、拒否の上書きが残っていない場合のみ。継承や所有者だけの許可を「全参加者にON」とは表示しない。
- 旧パネルのON表示や所有者だけに許可された既存部屋でも、再公開後にボタンを操作すると新しい判定で権限を設定する。全サーバーの既存権限を起動時に一括変更しない。
- 途中失敗はログと本人限定のエラーで通知する。一部反映の可能性を知らせ、成功メッセージは返さない。別の権限を壊すおそれのある一括復元は行わない。
- 初回作成・再設置・別Bot転送先へのパネル設置も、実際の設定から状態を表示する。権限が一致しない場合はOFFとして扱う。
- 砂浜のパネルでは、従来どおり画面共有ボタンを表示しない。

Botには対象VCの権限上書きを変更する権限が必要。Discordのサーバー所有者・管理者はチャンネル上書きを回避できるため、OFFで管理者まで禁止するものではない。タイムアウトなどDiscord側の別制約も解除しない。

変更の本番反映には再公開が必要。既存VCは再公開後に所有者が画面共有ボタンを操作する。残高・商品・VC所有者・閲覧公開範囲の変更は不要。
