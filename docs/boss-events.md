# 多機能Bot：ボス討伐イベント（銀行残高共有）

## 構成と反映

多機能Bot（TypeScript / discord.js）で動き、既存銀行Botと同じPostgreSQLの残高・武器・戦闘データを共有する。
鍛冶屋の武器と同じ残高を使い、外部APIやSQLiteへの移行は不要。
VPS上の旧ボスBot・旧武器DBは変更・移行しない。
本番へは新コードの再公開・起動が必要。起動時に日本語コマンド8件だけ個別登録する。
他のアプリ、サーバー専用コマンド、銀行コマンドを全件置換しない。
本番と同じBotを開発側で重複起動しない。

## コマンド

| コマンド | 権限・動作 |
| --- | --- |
| `/ボス開催` | Administrator。開催チャンネルへ告知 |
| `/ボス終了 確認:True` | Administrator。受付キャンセル・戦闘失敗。過去の行動代は返金しない |
| `/ボス料金設定 回復料金` | Administrator。回復1回の料金を1以上で設定。省略時は表示のみ。攻撃は無料固定 |
| `/ボス料金確認` | 本船員またはAdministrator。新しい討伐に使う料金 |
| `/ボス情報 ページ` | 本船員またはAdministrator。開催情報・HP・期限・参加者。途中の順位は表示しない |
| `/参加 モード:ソロ` | 本船員・武器所持必須。料金確認ボタンを押すとソロ戦開始 |
| `/参加 モード:パーティ` | 本船員・武器所持必須。料金確認後、2〜4人の受付へ参加 |
| `/攻撃` | 参加中の戦闘へ無料で攻撃。攻撃専用クールタイムのみ |
| `/回復` | 自分のHPを回復。確認済みの料金を消費 |

一般向け操作では本船員の所持を毎回ライブ取得で検証する。
管理者権限だけで本船員限定の参加・戦闘操作を迂回できない。
武器・ロール倍率は参加確定時に固定し、戦闘中の強化や管理者変更で入れ替えない。
サーバー内表示名は参加時のニックネームを保存して使用する。

## 開催時に管理者が指定する項目

必須：

- ボス：クラーケン、メガロドン、リヴァイアサン
- ソロHP、パーティHP（討伐ごとの独立HP）
- 制限秒（イベント全体の終了まで。最大7日）
- 受付秒（パーティ1組の募集時間。制限秒以下）
- 報酬（1討伐の総額）
- ボスの攻撃力・防御力
- プレイヤーHP、回復1回の基本回復量
- 反撃間隔（全参加者の成功した攻撃・回復の合計回数ごと）
- 会心率、会心倍率、Lvごとの追加ダメージ補正率

任意：

- 攻撃間隔秒：省略時5秒。0〜3600秒（0なら攻撃クールタイムなし）
- 回復間隔秒：省略時30秒。1〜3600秒
- 特殊イベント1つ：ボス攻撃力2倍／報酬2倍／与ダメージ1.5倍／回復量2倍
- 補正ロールとロール倍率（両方指定。@everyone不可）

戦闘数値や料金を推測して本番へ設定しない。
一般表示に武器の内部攻撃力・防御力を含めない。

## 料金と報酬

攻撃は常に **無料**。残高が0、または残高レコードがなくても攻撃できる。
既存の有料攻撃設定・開催中の戦闘も、更新後の新しい攻撃では引き落とさない。
回復は **有料**。既存の回復料金は維持し、管理者が1以上で設定する。
回復料金が未設定・旧設定0でも参加・攻撃は可能だが、その討伐では回復不可と表示する。
回復料金を後から設定しても既存戦闘の固定料金は変わらないため、次の討伐から有効になる。
回復料金変更は新規討伐に適用。既存の受付・戦闘はその討伐の固定料金を使う。
確認中に適用料金が変わったら、参加を拒否して再確認を求める。
参加確認自体では引き落とさない。
回復が成功した時だけ引き落とし、HP・クールタイム・台帳と同時に確定する。
過去の課金をさかのぼって返金・操作記録の再計算はしない。

報酬は参加者全員で均等分配（戦闘不能者も含む）。
端数はユーザーID昇順に1ずつ配り、配布合計を報酬総額と一致させる。
報酬2倍は **総額を2倍にした後** に分ける。
同ダメージのMVP・順位はユーザーID昇順で決める。
勝利時に全員の残高・台帳・戦闘状態を同時確定する。
残高上限や台帳書込みエラーでは、その攻撃／回復も含めて取り消し、
報酬未加算のまま成功通知を出さない。

満タンでの回復、戦闘不能、クールダウン中、受付中、期限切れ、
残高不足などの不成立操作では課金・戦闘更新をしない。

## 参加・期限・再起動

- サーバーごとに開催中のイベントは1つ。
- その中で複数の独立ソロ戦・パーティを開催可能。
- 同じユーザーは同じサーバーで同時に1討伐だけ参加可能。
- パーティは4人で即開始。受付期限に2〜3人なら開始、1人ならキャンセル。
- 全討伐はイベント共通の終了時刻まで。遅れて始めた戦闘は残り時間が短い。
- 討伐終了後は同イベントへ再参加可能（開催期間内）。無制限の同時参加は不可。
- ボスHP0で勝利、参加者全員HP0または制限時間で失敗。
- 過去の操作・参加・勝利を再受信しても二重課金・二重報酬にしない。
- 管理者の同一終了操作を再受信しても、後から開催したイベントを終了しない。

受付・戦闘・確認・操作記録はDBに保存。
Botの起動時と15秒ごとの復旧処理で、期限が過ぎた状態を評価する。
ユーザー操作時も期限を再評価するため、タイマーの遅延で期限後に課金しない。

## 戦闘ルール

攻撃と回復のクールタイムはユーザーごとに独立してDB保存する。
攻撃待ち中でも回復、回復待ち中でも攻撃が可能。再起動しても期限を維持する。
開催時の設定はそのイベント内で固定。旧イベントは攻撃5秒・回復30秒として動作する。
不成立操作ではタイマーを開始せず、並列操作・同一操作の再送で待ち時間や課金を回避しない。
攻撃回数の上限は設けず、戦闘終了・期限・戦闘不能・攻撃クールタイムのみで制限する。

基本攻撃：

`武器攻撃力 × (1 + (Lv - 1) × Lv補正率/100) × ロール倍率 × 乱数0.9〜1.1 × 会心倍率`

特殊イベント・武器スキルの倍率を適用後、ボス防御力を引く（最低1ダメージ）。
ボスHPを超えた分は与ダメージに加算しない。
通常の反撃はボス攻撃力・特殊行動倍率・暴走倍率・乱数から、
武器防御力の半分を引いて計算する（最低1）。

### 武器スキル

攻撃3回ごとに発動。回復コマンドは発動回数に数えない。

- 大剣「渾身斬り」：与ダメージ1.6倍
- 片手剣「連撃」：合計ダメージ1.4倍
- 槍「鉄壁」：次に受ける直接攻撃を半減
- 弓「貫通矢」：ボス防御力を無視
- 双剣「乱舞」：合計ダメージ1.6倍
- 杖「ヒール」：HP割合が最も低い生存者1人を最大HPの20%回復

杖の通常回復は基本量の1.5倍。回復イベントは回復をさらに2倍にする。
最大HPを超えず、戦闘不能者の復活はしない。

### ボス別特殊行動

- クラーケン：触手攻撃（単体1.2倍）／海流攻撃（全体0.8倍）／触手攻撃。
  HP30%以下で暴走し攻撃1.5倍。
- メガロドン：噛み砕き（単体1.4倍）／狩猟本能（最低HPを狙い1.2倍）／
  出血攻撃（単体1倍、次の2反撃で最大HP5%の出血）。
  HP50%以下で狂暴化し攻撃1.5倍。
- リヴァイアサン：大津波（全体1.2倍）／深海の咆哮（全体0.8倍、2反撃の被ダメージ1.2倍）／
  海神の加護（ボス最大HP10%回復）／絶望の渦（全体1.5倍）。
  HP20%以下で覚醒し攻撃2倍。

倍率・スキル詳細は初期戦闘ルールとしてコードに集約。
属性、PvP、レイド、図鑑など将来項目は今回未追加。

## 結果通知

開催チャンネルへ受付・開始・終了を通知する。
勝利ではボス名・討伐時間・人数・総ダメージ・MVP・各人の加算済み報酬、
失敗では残りHP・総ダメージ・人数・失敗理由を表示する。
上位3人のダメージ順位は **終了通知だけ** に表示。

通知状態も保存。送信失敗はバックオフして自動再送する。
送信の排他制御とDiscord nonceを併用し、通知再送で決済や報酬を再実行しない。
チャンネル削除・権限不足などはログに記録する。
