---
name: VPS database migration
description: ユーザーが指定した移行先と既存データ保持の要件
---

ユーザーは、このDiscord BotをConoHa VPSで動かすため、移行先データベースをSQLiteにし、既存データを引き継げるようにすることを要求した。

**Why:** 単に新しい空のデータベースでBotを起動する依頼ではなく、既存ユーザーデータを伴う稼働先の移行であるため。

**How to apply:** VPS向け対応では既存データの移行と検証を含める。データを移さず空のSQLiteへ切り替えたり、移行確認前に元のデータベースを削除したりしない。
