---
name: 島民の一般コマンド開放
description: 島民を理由とした共通制限を撤廃し、管理権限と個別の利用条件は維持する
---

銀行Bot・多機能Botとも、島民ロールによる一般コマンドの一括制限を設けない。

**Why:** ユーザーが「島民の使えるコマンドの制限を無くしてください」と依頼し、管理操作まで許可するかの確認に「一般コマンドのみ制限解除」と明示回答した。以前の島民向け許可コマンド一覧やゾンビ3コマンドだけの例外は、この共通制限について置き換えられる。

**How to apply:** 共通制限を通過させても管理者権限を付与したことにはしない。追放者の制限、各機能の参加条件、回数上限や料金は維持する。特に `/shop ticket-panel` の夜鴉・黒兵・管理者限定を島民へ広げず、料金変更・商品管理・イベント管理を開放しない。
