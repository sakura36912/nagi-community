---
name: Random match gender source
description: 裏募集の性別指定マッチングで使う判定ルール
---

裏募集の「男性指定」「女性指定」は、参加者本人の自己申告ではなく、凪ギルドの完全一致するDiscordロール名「男性」「女性」で相手の条件を判定する。両方またはどちらも持たないメンバーは、性別指定の相手条件を満たさない。

**Why:** ユーザーがDiscordロール判定を選択したため、BOT内の自己申告データとDiscordの権限状態が食い違う余地を避ける。

**How to apply:** マッチ成立時点の最新メンバーロールを取得し、指定なしは全員、男性指定は男性ロール、女性指定は女性ロールの相手だけを候補にする。参加者一覧や性別情報は待機中に公開しない。
