---
name: Database backup scope
description: 全ユーザーデータのJSONバックアップにおける環境と権限の境界
---

ユーザーはReplit Databaseに保存された全ユーザーデータのJSONバックアップを要求し、対象を「本番・開発の両方」と明示した。開発用接続先のエクスポートを本番データの取得として扱わない。

**Why:** 本番と開発のデータベースは別で、開発側のバックアップだけでは公開Botの実データを保護できないため。

**How to apply:** 新しい取得方法や保存先を追加しても、どの実行環境・接続先から取得したものかを区別し、本番と開発のどちらかを黙って省略しない。

全サーバー分を含むバックアップの取得はBotアプリケーション所有者に限定する。通常のDiscordサーバー管理者やアプリのチームメンバーであることだけでは許可しない。

**Why:** 各サーバーの管理権限は、他サーバーのユーザーID・残高・履歴などを読む権限ではない。確認時にも実行時にも所有者であることを確かめ、データは本人にだけ渡す。

**How to apply:** 管理者向けUI、取得API、定期バックアップ、復元機能を増やす際も、サーバー単位の管理権限とデータベース全体の取得権限を混同しない。
