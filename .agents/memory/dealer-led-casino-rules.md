**Rule:** Dealer-operated 丁半 and three-card poker settle with the existing system currency, not a dealer's own balance. A rule left without an initial value in the specification must remain unconfigured, and its game must be unavailable until an administrator explicitly sets it. Do not substitute example multipliers for defaults.

**Why:** The user explicitly chose the existing casino's system-funded settlement and chose to disable affected games until unspecified values are configured.

**How to apply:** When adding rules, payout options, or new modes to these dealer-operated games, distinguish stated defaults from illustrative examples and enforce required configuration before accepting bets.
