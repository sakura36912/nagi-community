---
name: Discord audit event types
description: 監査ログ調査でメッセージ削除とスレッド削除を取り違えないための注意
---

Discord監査ログのイベント指定は、インストール済みSDKの名前付き列挙値を使う。イベント番号を記憶だけで手書きしない。

**Why:** メッセージ削除をスレッド削除だと取り違えてもAPIが成功し、多数の無関係なログが返る。変更情報が空なのを「投稿情報が残っていない」と誤解しかけたが、正しいスレッド削除イベントには対象の投稿名が残っていた。

**How to apply:** 調査開始時にSDKのイベント名で対象を指定する。削除者・監査ログの実行者を投稿者と同一視しない。投稿者の特定には作成イベントの実行者と投稿IDを照合し、本文の保存有無は別に確認する。
