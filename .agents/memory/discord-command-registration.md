---
name: Discord command registration
description: Published Botの機能がDiscordのコマンド一覧に出ないときの運用上の注意
---

**Rule:** Botのコードを公開しても、Discord側のスラッシュコマンド定義が自動的に更新されるとは限らない。コマンド名やサブコマンドを追加・変更したら、Discord側の登録状態を別途確認する。特定コマンドだけの変更なら個別upsertを優先し、全件置換は避ける。

**Why:** 新しいカジノサブコマンドのコードは存在したが、Discordに残っていた定義は古く、ユーザーからはコマンドが見えなかった。全件置換を使うと、独立して同期されるサーバー専用コマンドが消えるおそれがある。

**How to apply:** コマンドが見つからない報告では、まずDiscordのグローバル・サーバー両方の登録内容とコードを照合する。必要な定義のみをDiscord APIで更新し、更新後に両スコープを読み直す。Bot本体が新コードで動いているかは登録とは別に確認する。
