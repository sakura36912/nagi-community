---
name: GitHub repository scope
description: Botごとに分けて非公開で保存するというユーザー指定
---

凪通貨BOTと多機能BOTは、それぞれ別の新規非公開GitHubリポジトリへ保存する。提案した名前は `nagi-currency-bot` と `nagi-community-bot` で、ユーザーはこの提案を選択した。

多機能BOTの実際の保存先には、ユーザーが指定した既存リポジトリ `nagi-community` を使用する。書き出し用フォルダ名とGitHubリポジトリ名が異なっても、新しいリポジトリを重複作成しない。

**Why:** 名前の提案後に、ユーザーが作成済みリポジトリのURLを指定したため。

**Why:** ユーザーは両Botを「それぞれGitHubへ保存」したいと依頼し、別々の新規非公開リポジトリを使う選択肢を明示的に選んだ。

**How to apply:** 1つの既存リポジトリへプロジェクト全体を送信することで代替しない。トークン・接続情報・実ユーザーデータ・バックアップや過去Git履歴は保存対象と区別する。ソースの準備とGitHubへの送信完了を分けて報告する。

ダウンロード案内では、UIで開いたファイル名だけでなく、実パスとサイズを確認する。

**Why:** iPadでファイルを探す過程で、正常な生成済みZIPとは別に同名の0バイトファイルが開かれた。名前の一致だけでは正しいダウンロード先を確認できない。

**How to apply:** 空の同名ファイルを案内し続けず、ZIPの整合性を確認する。ダウンロードしやすい場所にコピーする場合、そのコピーもGitとデプロイの対象から除外する。
