# 🎰 凪-Nagi-｜賭博師ディーラーBOT 仕様書
対象ゲーム：
・丁半
・スリーカードポーカー

## 1. 目的

凪-Nagi-の賭博場で、
**賭博師がディーラー側としてゲームを進行する賭博システム**を実装する。

プレイヤーだけで自動的に遊ぶBOTではなく、

**賭博師が開催 → 参加受付 → 締切 → ゲーム進行 → 勝敗確定 → 精算**

までを管理する方式とする。

対象ゲームは、

1. 丁半
2. スリーカードポーカー

の2種類。


━━━━━━━━━━━━━━━━━━
# 2. 共通利用条件

ゲームは、
**指定された賭博場VCにディーラーと参加者が入っている場合のみ利用可能**とする。

### 利用条件

・ディーラーが賭博師ロールを所持している
・ディーラーが賭博場VCにいる
・参加者も同じ賭博場VCにいる
・進行中のゲームへ重複参加していない
・必要な掛け金を所持している


### 利用可能ロール

・賭博師
・賭博統領
・指定された管理者


━━━━━━━━━━━━━━━━━━
# 3. 共通掛け金

初期設定：

最低掛け金：
**1,000＄**

最高掛け金：
**10,000＄**

※管理設定から変更可能にする。


━━━━━━━━━━━━━━━━━━
# 4. 共通ゲーム状態

BOT内部では以下の状態を管理する。

### RECRUITING
参加受付中

### CLOSED
受付終了

### PLAYING
ゲーム進行中

### RESULT
結果確定

### PAYOUT
精算中

### FINISHED
終了

### CANCELLED
キャンセル済


状態に合わない操作は受け付けない。

# 6. 共通参加パネル

ゲーム開始時、
Embed＋ボタンで参加受付を行う。

表示内容：

・ゲーム名
・ディーラー
・掛け金範囲
・参加人数
・現在の状態

・参加取消
・掛け金変更

不可。

以下を必ず保証する。

・二重払い禁止
・二重没収禁止
・結果確定後の再抽選禁止
・BOT再起動による重複精算禁止
・返金対象ゲームの自動返金
・精算履歴保存

# 18. スリーカードポーカー｜概要

プレイヤーとディーラーが、
それぞれ3枚のカードを使用して勝負する。

プレイヤー同士ではなく、

**プレイヤー vs ディーラー**

形式とする。

ディーラー役は賭博師。


━━━━━━━━━━━━━━━━━━
# 19. 使用カード

通常の52枚デッキを使用。

ジョーカーなし。

1ゲームごとに十分なシャッフルを行う。

同一ゲーム内で
同じカードが重複して配られないようにする。


━━━━━━━━━━━━━━━━━━
# 20. 基本進行

1. 賭博師がゲーム開始
2. プレイヤー募集
3. 掛け金入力
4. 募集締切
5. プレイヤーへ3枚配布
6. ディーラーへ3枚配布
7. プレイヤーが「続行 / 降りる」を選択
8. ディーラーのカード公開
9. 役を比較
10. 勝敗決定
11. 精算


━━━━━━━━━━━━━━━━━━

# 24. 役の強さ

スリーカードポーカーの役順位は、
以下の順とする。

強い
↓


### 1. ストレートフラッシュ
同じスート＋連続した3枚

### 2. スリーカード
同じ数字3枚

### 3. ストレート
連続した3枚

### 4. フラッシュ
同じスート3枚

### 5. ペア
同じ数字2枚

### 6. ハイカード
上記以外


弱い


※役順位は設定で変更せず、
基本ルールとして固定。


━━━━━━━━━━━━━━━━━━
# 25. 同じ役の場合

同役の場合は、
役を構成する数字の強さで比較する。


例：

K-K-5
vs
Q-Q-A

→ Kのペアが勝利


ハイカードの場合：

最も高いカードから比較する。

それでも同じ場合は、
次に高いカードを比較。


完全同値の場合：

**引き分け**
として掛け金返却。


━━━━━━━━━━━━━━━━━━
# 26. Aの扱い

Aは基本的に最上位カードとして扱う。

ストレート判定については、

A-2-3

を有効とするかどうかは
管理設定で変更可能にする。

AI実装時に勝手に固定しないこと。


━━━━━━━━━━━━━━━━━━
# 27. ディーラー資格条件

スリーカードポーカーでは、
ディーラー側に最低成立条件を設定可能にする。

例：

**Q以上のハイカード**

をディーラー成立条件とする方式。

ただし、
この条件を採用するかどうかは管理側で最終決定するため、

ON / OFF設定可能にすること。

# 31. 複数人参加時

複数人が参加していても、

**各プレイヤー vs 同一ディーラー**

として個別判定する。


例：

参加者5名

ディーラー1名

→ 5名それぞれ個別に勝敗判定。


プレイヤー同士では勝敗比較しない。

# 42. 最重要仕様

このBOTの目的は、

**「賭博師がディーラーとして賭場を運営すること」**

である。

完全自動カジノにはしない。

BOTは、

・参加受付
・掛け金管理
・ランダム処理
・カード処理
・勝敗判定
・配当
・記録

を担当。

実際のゲーム進行は、

**賭博師が主導する。**
